# AXONVERTEX Agent Studio

This package imports the AXONVERTEX Coding Agent v0.3.0 source and adds a **separate read-only Operator Workbench (0.7D1)**. The Coding Agent retains its original interactive behavior; it is not a read-only tool.

For the setup and acceptance requirements, read [README-0.7D1.md](README-0.7D1.md) in the source repository and `docs/operations/checkpoint2e-operator-workbench-v07d1.md` in the monorepo.
